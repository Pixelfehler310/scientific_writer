# Scientific Writer State

Persönliches, projektübergreifendes State-Repository für den Codex-Skill `write-seminar-paper`.

- `profile.yaml` enthält bestätigte persönliche und studienbezogene Standardwerte.
- `projects/<project-id>/` enthält portable Workflow-Zustände und Arbeitsartefakte.
- Projektlokale Runtime-Daten wie Builds, Template-Snapshots, Locks und Audits bleiben im jeweiligen Projekt.
- Der maschinenspezifische Locator liegt unter `scientific-writing/location.yaml` im Betriebssystem-Konfigurationsordner.

Änderungen werden weder automatisch committet noch gepusht.
